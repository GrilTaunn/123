# ARQ

Первая полноценная статическая версия образовательной платформы ARQ.

## Запуск
Откройте `index.html` локально или опубликуйте репозиторий через GitHub Pages.

## Уже работает
- Главная, курсы, практика, тесты, материалы, прогресс, пробный экзамен, «О проекте»
- Интерактивные тесты и автоматический результат
- Сохранение прогресса в localStorage
- Отметка уроков и практических заданий
- Поиск по библиотеке
- Адаптивный desktop/tablet/mobile интерфейс
- Базовые события аналитики в localStorage

## Следующий production-этап
Подключить Auth + БД + API + object storage + реальную аналитику. В текущей версии пользовательские данные хранятся только в браузере.
